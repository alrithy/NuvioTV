# Nuvio Superfork

This fork contains a structured integration project that combines selected, proven capabilities from important Nuvio forks on top of current official Nuvio.

**Coding agent:** read `AGENTS.md` first.

**Human:** read `docs/PROJECT_STATUS.md` then `docs/INDEX.md`.

Superfork product integration branch: `superfork/integration`.

The repository's legacy/default `dev` branch is not the Superfork development target until the GitHub default branch setting is migrated.
